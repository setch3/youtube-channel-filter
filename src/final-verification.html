使用方法

  1. 拡張機能の読み込み
    Chrome > その他のツール > 拡張機能 > パッケージ化されていない拡張機能を読み込む
    → srcフォルダを選択
  2. 設定の確認
    拡張機能のオプションページを開く
    → 「Google検索結果でYouTube動画をフィルタリングする」が有効になっていることを確認
  3. チャンネルの追加
    ブロックしたいチャンネルのID/@ハンドルまたはチャンネル名を追加
  4. 動作確認
    Google検索でYouTube動画を含む検索を実行
    → ブロック対象チャンネルの動画が非表示になることを確認
