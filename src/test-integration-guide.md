# Google検索フィルタリング統合テストガイド

## 概要

このドキュメントは、Google検索フィルタリング機能の統合テストを実行するための手順とチェックリストを提供します。

## テストファイル構成

- `test-google-integration.html` - 統合テスト用のWebページ
- `test-google-integration.js` - 統合テスト用のJavaScript
- `test-google-live.js` - 実際のGoogle検索ページでのライブテスト
- `test-integration-guide.md` - このガイドドキュメント

## テスト実行手順

### 1. 事前準備

#### 1.1 拡張機能の読み込み
1. Chrome拡張機能管理ページ（`chrome://extensions/`）を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `src`フォルダを選択して読み込む

#### 1.2 テストデータの準備
```javascript
// テスト用のブロックリスト設定
bannedIds: ['@testchannel1', 'UC1234567890', 'testuser']
bannedNames: ['テストチャンネル', 'Test Channel', 'ブロック対象']
```

### 2. 統合テストの実行

#### 2.1 ローカルテスト環境での実行
1. `src/test-google-integration.html`をブラウザで開く
2. 「全テスト実行」ボタンをクリック
3. 各テストセクションの結果を確認

#### 2.2 実際のGoogle検索ページでのテスト
1. Google検索ページ（`https://www.google.com/search?q=youtube`）を開く
2. デベロッパーツールのコンソールを開く
3. `src/test-google-live.js`の内容をコンソールに貼り付けて実行
4. または、以下のコマンドでテストを実行：
   ```javascript
   googleSearchLiveTest.runAll()
   ```

## テストカテゴリ別チェックリスト

### 1. Google検索クエリフィルタリングテスト

#### ✅ 要件1.1: YouTube動画検出機能
- [ ] Google検索結果でYouTube動画リンクが正しく検出される
- [ ] 複数のセレクタパターンで動画要素を検出できる
- [ ] 通常動画とShortsの両方を検出できる
- [ ] 検出されたリンクが有効なYouTube URLである

#### ✅ 要件1.2: チャンネル情報抽出機能
- [ ] YouTube URLからチャンネルIDを抽出できる
- [ ] @ハンドル形式のチャンネル情報を抽出できる
- [ ] Google検索結果のテキストからチャンネル名を抽出できる
- [ ] 抽出に失敗した場合でも処理が継続される

#### ✅ 要件1.3: フィルタリング判定機能
- [ ] ブロックリストのチャンネルIDと正しく照合される
- [ ] ブロックリストのチャンネル名と正しく照合される
- [ ] 大文字小文字を無視した照合が行われる
- [ ] ブロック対象の動画要素が非表示になる

### 2. YouTube内フィルタリング連携テスト

#### ✅ 要件2.1: 共通設定の使用
- [ ] 既存のbannedIds設定が正しく読み込まれる
- [ ] 既存のbannedNames設定が正しく読み込まれる
- [ ] YouTube内とGoogle検索で同じブロックリストが使用される

#### ✅ 要件2.2: 設定変更の即座反映
- [ ] 拡張機能設定でチャンネルを追加すると即座に反映される
- [ ] 拡張機能設定でチャンネルを削除すると即座に反映される
- [ ] 設定変更後にページをリロードしなくても反映される

#### ✅ 要件2.3: ストレージ同期
- [ ] Chrome sync storageに設定が正しく保存される
- [ ] 設定変更がリアルタイムで同期される
- [ ] 複数のブラウザインスタンス間で設定が同期される

### 3. 動的コンテンツ監視テスト

#### ✅ 要件3.1: MutationObserver動作
- [ ] MutationObserverが正しく設定される
- [ ] DOM変更が検知される
- [ ] 新しく追加された要素が処理される

#### ✅ 要件3.2: 動的追加要素のフィルタリング
- [ ] 「もっと見る」で追加された動画がフィルタリングされる
- [ ] 無限スクロールで追加された動画がフィルタリングされる
- [ ] 検索クエリ変更後の新しい結果がフィルタリングされる

#### ✅ 要件3.3: 検索結果の動的更新対応
- [ ] 検索結果の動的読み込みに対応している
- [ ] ページ遷移なしでの検索結果更新に対応している
- [ ] AJAXによる部分更新に対応している

### 4. パフォーマンステスト

#### ✅ 要件4.1: 効率的なDOM操作
- [ ] YouTube動画要素のみを対象とした効率的なクエリが実行される
- [ ] 不要なDOM走査が避けられている
- [ ] セレクタの実行時間が許容範囲内（10ms以下）

#### ✅ 要件4.2: 最小限のDOM操作
- [ ] 必要最小限の要素のみが非表示にされる
- [ ] DOM操作がバッチ処理される
- [ ] 大量の検索結果でもパフォーマンスが維持される

#### ✅ 要件4.3: ページ応答性の維持
- [ ] フィルタリング処理がページの読み込み速度に影響しない
- [ ] ユーザーインタラクションがブロックされない
- [ ] メモリ使用量が適切な範囲内（1MB以下）

### 5. 設定オプションテスト

#### ✅ 要件5.1: 有効/無効設定
- [ ] Google検索フィルタリングの有効/無効が切り替えられる
- [ ] 無効時にフィルタリングが実行されない
- [ ] 設定がChrome sync storageに保存される

#### ✅ 要件5.2: 設定UI
- [ ] options.htmlに設定項目が表示される
- [ ] チェックボックスの状態が正しく反映される
- [ ] 設定変更が即座に保存される

#### ✅ 要件5.3: 設定同期
- [ ] 設定変更が他のブラウザインスタンスに同期される
- [ ] 設定の初期値が正しく設定される
- [ ] 設定の読み込みエラーが適切に処理される

## テスト実行時の注意事項

### 環境要件
- Chrome拡張機能として動作する環境
- Google検索ページへのアクセス権限
- Chrome Storage APIの利用権限

### テストデータ
- 実際のYouTubeチャンネルIDを使用する場合は、テスト後にクリーンアップする
- テスト用のモックデータを使用して実際の設定に影響しないようにする

### デバッグ情報
- コンソールログを有効にして詳細な実行情報を確認する
- パフォーマンス測定結果を記録する
- エラーが発生した場合はスタックトレースを保存する

## トラブルシューティング

### よくある問題と解決方法

#### 1. YouTube動画が検出されない
- Google検索でYouTube動画が含まれるクエリを使用する（例：「youtube 音楽」）
- セレクタが最新のGoogle検索レイアウトに対応しているか確認する
- デベロッパーツールでDOM構造を確認する

#### 2. フィルタリングが動作しない
- 拡張機能が正しく読み込まれているか確認する
- Google検索フィルタリング設定が有効になっているか確認する
- ブロックリストに適切なチャンネル情報が設定されているか確認する

#### 3. 設定が保存されない
- Chrome Storage APIの権限が付与されているか確認する
- ストレージの容量制限に達していないか確認する
- 同期設定が有効になっているか確認する

#### 4. パフォーマンスが悪い
- セレクタの効率性を確認する
- DOM監視の範囲を最適化する
- 不要な処理を削除する

## テスト結果の評価基準

### 成功基準
- 全テストの成功率が90%以上
- パフォーマンステストで許容範囲内の結果
- 実際のGoogle検索ページでの動作確認

### 警告基準
- 一部のセレクタが無効（Google検索レイアウト変更の可能性）
- パフォーマンスが基準値を若干上回る
- 一部の設定項目で問題が発生

### 失敗基準
- 基本的なYouTube動画検出ができない
- フィルタリング機能が全く動作しない
- 設定の保存・読み込みができない
- 重大なパフォーマンス問題

## 継続的テスト

- Google検索ページの構造変更に対応するため、定期的にテストを実行する
