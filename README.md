# YouTube Channel Filter

この Chrome 拡張機能は指定した YouTube チャンネルの動画を非表示にします。YouTube内だけでなく、**Google検索結果**に表示されるYouTube動画も対象にできます。

## 主な機能

### YouTube内でのフィルタリング
- 検索結果、ホーム画面、関連動画欄での動画非表示
- ショートの「最新のショート」セクションでの非表示
- チャンネルID/@ハンドルと表示名の両方でブロック可能
- 日本語チャンネル名にも対応
- ショート動画の一括非表示オプション

### Google検索結果でのフィルタリング（新機能）
- Google検索結果に表示されるYouTube動画の自動非表示
- 既存のYouTube内設定と同じブロックリストを使用
- 動的コンテンツ（無限スクロール等）にも対応
- 設定で有効/無効の切り替え可能

## 使い方

### 初期設定
1. Chrome の **その他のツール > 拡張機能 > パッケージ化されていない拡張機能を読み込む** で `src` フォルダを選択します。
2. 拡張機能のオプション画面を開きます。

### チャンネルのブロック設定
1. **ID/@ハンドル** セクション：
   - チャンネルID（例：`UC1234567890`）
   - @ハンドル（例：`@channelname`）
   - ユーザー名（例：`username`）
2. **チャンネル名** セクション：
   - 表示名（例：`テストチャンネル`）
   - 部分一致で動作（例：`テスト`で`テストチャンネル`がブロック）

### 追加オプション
- **ショート動画を非表示**: YouTube内でショート動画を一括非表示
- **Google検索結果でYouTube動画をフィルタリングする**: Google検索でのフィルタリング機能の有効/無効

### 動作確認
- YouTube内：設定したチャンネルの動画が自動的に非表示
- Google検索：YouTube動画を含む検索で、ブロック対象チャンネルの動画が非表示

## 技術仕様

- **対応サイト**: `*.youtube.com/*`, `*.google.com/*`
- **ストレージ**: Chrome同期ストレージ（複数ブラウザ間で設定共有）
- **動的監視**: MutationObserverによるリアルタイム処理
- **パフォーマンス**: 最適化されたセレクタとバッチ処理

## トラブルシューティング

### Google検索でフィルタリングが動作しない場合
1. オプション画面で「Google検索結果でYouTube動画をフィルタリングする」が有効になっているか確認
2. ブラウザを再起動してみる
3. 拡張機能を一度無効にして再度有効にする

### 設定が反映されない場合
- Chrome同期が有効な場合、設定の同期に時間がかかることがあります
- ページを再読み込みして確認してください
